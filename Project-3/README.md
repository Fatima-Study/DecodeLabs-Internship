# Overview

The **Phishing Awareness Analysis** project was developed as part of the **DecodeLabs Cyber Security Internship**. The objective of this project is to analyze simulated phishing emails and messages by identifying suspicious senders, misleading domains, phishing keywords, suspicious URLs, and social engineering techniques. The project helps improve phishing awareness through structured analysis and risk classification.

---

# Problem Statement

Phishing attacks remain one of the most common cybersecurity threats, targeting users through deceptive emails and messages. Many users unknowingly interact with malicious links or provide sensitive information. This project aims to identify phishing indicators, classify the associated risks, and improve awareness of common phishing techniques.

# Methods

The project follows these steps:

1. Collect simulated phishing emails and messages.
2. Analyze sender information and email domains.
3. Review message content for urgency, threats, and suspicious requests.
4. Identify phishing keywords and suspicious URLs.
5. Compare findings with a phishing red-flag checklist.
6. Classify each message according to its risk level.
7. Document the analysis and security recommendations.

# Key Insights

- Urgent language is one of the strongest phishing indicators.
- Suspicious URLs often imitate trusted organizations.
- Fake rewards and account verification requests are commonly used to deceive users.
- Sender and domain verification significantly improves phishing detection.
- Multiple phishing indicators together provide stronger evidence than a single warning sign.

# Final Recommendations

- Verify sender email addresses before responding.
- Avoid clicking suspicious links or opening unexpected attachments.
- Never share passwords, OTPs, or sensitive information through email.
- Inspect URLs carefully before visiting websites.
- Report suspected phishing attempts to the appropriate security team.
- Conduct regular phishing awareness training.
